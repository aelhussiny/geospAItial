# geospAItial: The Modern ArcGIS SDK Journey 🚀

Welcome to the official repository for the [**geospAItial**](https://www.linkedin.com/newsletters/7442864728705740800/) newsletter. This is a "living" resource dedicated to navigating the evolution of the **ArcGIS Maps SDK for JavaScript**, from the foundations of **3.x** and **4.x** into the AI-integrated, component-first era of **5.0 and beyond**.

## 📖 About This Project
After 10 years of building with Esri technology, I’m documenting the shift toward **Agentic Mapping** and **Semantic Versioning**. These tutorials are designed to be **bite-sized**, production-ready, and easy to clone.

> **New to the 5.0 shift?** Start with the [Release Notes](https://developers.arcgis.com/javascript/latest/release-notes/) to see what’s changed in the core architecture.

## 🚀 Getting Started
Each folder in this repository is a standalone project. To run a sample locally:

1. **Clone the repo:**
   ```bash
   git clone [https://github.com/aelhussiny/geospAItial.git](https://github.com/aelhussiny/geospAItial.git)
   ```

2. **Navigate to the appropriate tutorial folder:**
   ```bash
   cd part-01-migration
   ```

3. **Install and Run:**
   ```bash
   npm install
   npm run dev
   ```
